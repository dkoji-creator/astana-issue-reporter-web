# Spirit Catchers — состояние проекта

Последняя опубликованная версия плейса: **49** (place 99980756426085, universe 7664327129).
Ветка: `ccr-94001311-wpmtrg`, папка `spirit-catchers/`.

## Как собирать и публиковать
- Сборка: `rojo build -o SpiritCatchers.rbxlx` (в папке spirit-catchers).
- Публикация: `POST https://apis.roblox.com/universes/v1/7664327129/places/99980756426085/versions?versionType=Published` с `x-api-key` (ключ подставляет прокси сессии), тело — `.rbxlx`, `Content-Type: application/xml`.
- **Смоук-тест (обязательно перед публикацией):** `node tools/sim/run.mjs` — настоящий компилятор Luau (npm `luau-web`, WASM) + эмулятор Roblox (tools/sim/roblox.luau) + сценарий (tools/sim/scenario.luau). Должно быть «0 ошибок».
- Перед публикацией обязательно:
  1. синтаксис: stylua `--check` по всем `.luau`;
  2. **лимит 200 локальных переменных** в главном клиентском скрипте (сейчас ~132). Новый код добавлять внутрь `do ... end` блоков разделов;
  3. `%d` в `:format()` только с целыми числами (`math.floor`);
  4. нельзя вызывать `local function` из кода выше её объявления.
  5. **лимит 200 локальных переменных и на сервере** (Main.server ~185). Новые remote-объекты сервера класть в таблицу `RX`.

## Что есть в игре
- Мир «Квартал фонарей»: улица, площадь с алтарём, канал, храмовый сад (3 вида), бамбуковая роща (ур. 3), ночной рынок (8 видов).
- 18 духов, 7 тиров редкости, 7 разновидностей (до «Бесконечный» 1 к 5000).
- Поиск: тени видны только в узком луче, духи прячутся, следы, выслеживание из Атласа.
- Ловля: мини-игра с зоной, совместная ловля.
- Удача: уровень, Фортуна, перерождения, пасс, зелье, Красная луна; рулетка, объявления сервер/все сервера.
- Прогресс: уровни, таланты (5×10), перерождение, улучшения (банка/луч/сила), задания, награды коллекции, ежедневный подарок.
- Донат (developer products, ID в Config/Monetization.luau), коды BETA/WELCOME, админка (UserId 8432365972), телепорты и порталы, доска рекордов.
- Музыка и звуки работают (доступ выдан в Creator Hub).

- Админка: команды `mod` (следующий модификатор), `season` (+3 уровня сезона), `raid` (начать рейд).
